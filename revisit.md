# Problems to Revisit

Spaced-repetition queue. A problem enters at Pass 1 when you first archive it, and the agent maintains this file per the `interview-practice-workflow` skill. A problem that reaches Pass 4 cleanly is removed from the table.

## Revisit queue

Sorted by next-eligible date. A past/today date means it's already eligible now.

| # | Problem | Archive | Pass | Last solved | Next eligible | Notes |
|---|---------|---------|------|-------------|----------------|-------|

## Revisit checklist (per problem)

- [ ] State approach out loud before coding
- [ ] State time and space complexity
- [ ] Code from scratch without looking at archived solution
- [ ] Run `npm run test:active` after re-implementing in `active/`
